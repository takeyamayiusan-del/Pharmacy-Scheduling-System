1. 這套系統能幫我做什麼？

家禾體系排班系統是竹山耀聖藥局與集集家禾藥局共用的工作平台，把過去用紙本或 LINE 溝通的人事作業，集中到同一個地方完成。

功能類別您可以做的事
班表查看全店或個人班表、選下月排休、匯出班表圖片
出勤手機 GPS 上下班打卡、申請補登、查看工時與遲到紀錄
假勤請假、換班、加班、假別遞延（集集）申請與追蹤審核進度
薪資查詢已發布薪資單、下載 PDF（店長／會計負責結算與發布）
店內協作公告板留言、訂餐、店務叫藥／採購／客訂、教育訓練
重要觀念：您登入後只會看到自己店別的資料。老闆與會計在處理薪資時可以切換店別，一般員工無需也無法看到另一店的內容——這是正常的。

誰用哪個登入分頁？

身分登入分頁登入後預設頁面
一般員工員工登入上下班打卡
店長、副店、主任、會計、老闆管理端登入月曆式班表
帳號與初始密碼由店長建立後告知。第一次登入請盡快請店長協助修改密碼，勿與他人共用帳號。

2. 登入與認識畫面

2.1 登入步驟

  1. 開啟系統登入頁（網址由店長提供，通常為店內電腦書籤或 QR Code）。
  2. 依身分點選上方分頁：員工登入 或 管理端登入。
  3. 輸入帳號、密碼，按「登入」。
  4. 若跳出公告、薪資通知或排休提醒，請先閱讀後關閉，再開始操作。

2.2 畫面各區說明

位置內容
上方橫列系統名稱、店名、您的姓名與職稱、通知鈴鐺、登出
左側選單各功能入口；手機版點左上角 ≡ 開啟
中間主畫面目前功能的操作區
問號提示部分頁面有 ? 圖示，點開可看該頁說明

2.3 登入後常見跳出視窗

  • 重要公告：店長發布的必讀訊息（例如公休、活動、店規異動）。
  • 薪資通知：當月薪資已發布，提醒您至「薪資查詢」查看。
  • 排休提醒：每月 20 日起，若您尚未填寫下月排休，系統會提醒您前往「排休選擇」。

兩店使用同一套系統，但店規不同。操作方式相同，請特別留意下列差異，避免排休或請假額度搞錯。

6. 我的班表 — 查看個人班表

全員 左側選單 → 我的班表

6.1 畫面說明

  • 以月曆方式顯示只有您自己的班別。
  • 每格顯示當日班別代碼與名稱（例如 B 白班、X 休假）。
  • 若當日有請假核准，會顯示假別或休假標記。
  • 上方可切換月份。

6.2 手機使用技巧

  1. 若格子較多、畫面較擠，請用手指左右滑動查看完整一週。
  2. 按「匯出圖片」可將整張月班表存成圖片，方便存到手機相簿或傳給家人。
  3. 匯出的圖片與電腦版內容相同，不會被裁切。
小提示：建議每週固定查看一次「我的班表」，確認下週班別與排休是否正確，有問題及早向店長反映。

7. 排休選擇 — 填下個月休假日

員工 左側選單 → 排休選擇

7.1 什麼時候要填？

每月 20 日左右起，系統會提醒您填寫下個月想休的日期。請在店長公告的截止日前完成。

7.2 操作步驟

  1. 進入「排休選擇」，確認上方顯示的是下個月（可用箭頭切換月份）。
  2. 點選日期格子：再點一次可取消。變更會立即儲存，無需另外按送出。
  3. 注意畫面上的額度提示：週六尚可排休幾天、平日尚可排休幾天等。
  4. 若選到不可選的日期（例如週日公休、額度已滿），系統會提示原因。
  5. 填完後可在「我的班表」預覽下月是否正確。

7.3 特殊情況

情況說明
晚班／全天班排休若當天班別需要涵蓋晚班，系統可能要求您選擇「誰代晚班」或填寫公告
只能休半天（集集）點選日期後需選擇上午或下午，並指定當天上班班別
店長已鎖定該月排休已鎖定，無法再修改，請洽店長
平日不排休規則若您個人被勾選「平日不排休」，平日格子無法選取
排休不等於請假！排休是預先告訴店長下月想休哪天；若臨時有事，仍須另外走「請假申請」。

8. 上下班打卡（含休假日加班）

員工 左側選單 → 上下班打卡

8.1 打卡前準備

  • 使用手機或平板，並允許瀏覽器使用定位（GPS）。
  • 建議使用 Chrome 或 Edge 瀏覽器。
  • 人須在店點附近（系統設定的打卡範圍內）。

8.2 一般上班日打卡

  1. 打開打卡頁，等待上方 GPS 狀態變為綠色「已在打卡範圍內」。
  2. 畫面會顯示今日班別、應上班／下班時段。
  3. 在對應時段按大按鈕完成「上班打卡」或「下班打卡」。
  4. 若遲到，系統會要求填寫遲到原因後才能完成上班打卡。
  5. 下班若超過規定時間，畫面可能引導您一鍵申請加班。

8.3 畫面狀態說明

GPS 狀態意義您該做什麼
定位中…正在取得位置稍等幾秒，到戶外或窗邊訊號較佳
無法取得定位瀏覽器未允許 GPS到設定開啟定位權限，重新整理頁面
不在打卡範圍內距離店點太遠移動到店內或店門口再試；仍不行請告知店長
已在打卡範圍內可以打卡按對應按鈕打卡

8.4 休假日來店加班

若今日班表顯示「休假」但您實際來店上班，請使用畫面下方的專用按鈕：

  • 上班打卡（加班）：開始加班時按。
  • 下班打卡（加班）：結束加班時按。

畫面會顯示今日加班進度與已打卡紀錄，方便確認是否成對打卡。

8.5 漏打卡怎麼辦？

請至「打卡補登」提出申請，等店長核准。集集店員工每月補登次數有上限（2 次），請盡量養成當下打卡習慣。

9. 請假申請

全員 左側選單 → 請假申請

9.1 新增請假

  1. 按「新增請假」或類似按鈕。
  2. 選擇假別：特休、事假、病假、婚假、喪假、產假、補休…等。
  3. 選擇日期與時段：全天、上午、下午，或自訂起迄時間。
  4. 填寫事由（必填）。
  5. 若假別需要證明（如病假），可上傳附件。
  6. 確認後送出。狀態會顯示「待審核」直到店長（或依店規多關審核）核准。

9.2 假別小知識

假別重點提醒
特休會扣除年度特休餘額；可點「年度特休總表」查看配額
補休使用先前加班換得的補休時數
病假／事假系統會依店規顯示是否超過建議天數（僅提醒，不會自動擋下）
半日假選上午或下午，系統依班表計算請假時數

9.3 核准後會發生什麼？

  • 班表上該日會顯示休假或假別。
  • 當日打卡規則會依請假時段調整（例如只請上午，下午仍須正常打卡）。
  • 已請假的時段不會計入遲到。
建議越早申請越好，尤其連假或旺季，方便店長排班與找代班。

10. 換班申請

全員 左側選單 → 換班申請

  1. 按「新增換班」。
  2. 選擇換班對象（同事）。
  3. 選擇您的日期與對方的日期（互換班別）。
  4. 填寫原因後送出。
  5. 待店長審核通過後，兩人班表會自動更新。
無法換班的情況：週日公休日不可換班；若其中一人當日已有請假或額度不符，店長可能駁回。請事先與對方口頭確認再送出申請。

11. 加班申請

全員 左側選單 → 加班申請

11.1 什麼時候要申請？

  • 下班後實際工作超過班表時間。
  • 打卡頁引導您申請加班時。
  • 休假日來店上班（也可在打卡後補申請）。

11.2 操作步驟

  1. 選擇加班日期。
  2. 填寫實際加班起迄時間（或選擇系統帶入的打卡時間）。
  3. 選擇給付方式：加班費 或 補休（依店規，部分情況系統會建議或限制選項）。
  4. 填寫事由後送出，等待審核。
店規差異：集集店加班未滿 30 分鐘無法申請；竹山店加班超過 30 分鐘時，系統可能建議改選補休。詳見第 4 章對照表。

12. 打卡補登

全員 左側選單 → 打卡補登

  1. 按「新增補登申請」。
  2. 選擇漏打卡的日期。
  3. 選擇要補登的是上班或下班（可分開申請）。
  4. 填寫實際時間與原因。
  5. 送出後待店長審核；核准後工時統計會納入該筆紀錄。
集集店員工每月補登以 2 次為限；店長在「打卡管理」代登不計入您的次數。

13. 假別遞延（集集店）

集集店員工 左側選單 → 假別遞延（竹山店無此選單）

當特休或補休即將到期、來不及休完時，可申請將剩餘時數遞延至下一期間使用。

  1. 進入假別遞延頁，查看可遞延的餘額。
  2. 新增申請，選擇假別與欲遞延時數。
  3. 填寫原因後送出。
  4. 依店規經店長 → 副店 → 老闆順序審核。

14. 工時統計與薪資查詢

14.1 工時統計

全員 左側選單 → 工時統計

  • 預設顯示上個月資料（方便對帳）。
  • 可看到每日班別、打卡時間、加班、請假、遲到分鐘數等。
  • 店長可看全店；員工僅看自己。
  • 可匯出 CSV 或打卡 PDF 留存。

14.2 薪資查詢

全員 左側選單 → 薪資查詢

  1. 選擇要查看的月份（僅顯示店長／會計已「發布」的月份）。
  2. 查看底薪、津貼、加班費、獎金、扣款等明細。
  3. 按「匯出 PDF」或「匯出 Excel」下載薪資單。
若某月份看不到資料，代表該月薪資尚未發布，請詢問店長或會計預計發布時間。

15. 通知中心與公告板

15.1 通知中心

上方鈴鐺圖示或左側「通知中心」可查看：

  • 請假／換班／加班／補登的審核結果
  • 薪資發布通知
  • 排休提醒、系統訊息

點選通知可跳到相關頁面。已讀通知會標記，亦可一次全部標為已讀。

15.2 公告板（在月曆式班表頁上方）

公告類型誰可發用途
重要公告店長全店必讀訊息
公休／活動通知店長臨時公休、店內活動
代班需求員工找人代班時發布
交班留言員工交班事項、客戶備註

16. 訂餐與店務需求

16.1 訂餐

全員 左側選單 → 訂餐

  1. 查看進行中的訂餐活動（由某位同事或店長發起）。
  2. 點進活動，選擇品項與數量。
  3. 送出訂單；截止前可修改。
  4. 負責人訂購完成後會標記「已訂購」，並可發公告通知大家。

16.2 店務需求

全員 左側選單 → 店務需求

分為多個分頁，依工作需要使用：

分頁用途
叫藥登記需向供應商叫補的藥品
日常採購非藥品耗材、日用品採購需求
客人訂購客人預訂商品登記
客訂管理追蹤訂單狀態、標記完成、匯出清單

店長可編輯品項分類；員工可新增需求單。完成的訂單可匯出 Excel 或 PDF 留存。

17. 教育訓練

全員 左側選單 → 教育訓練

  1. 查看被指派的課程清單與完成進度。
  2. 點進課程，閱讀教材（文字、圖片或連結）。
  3. 若有測驗，依題目作答後送出。
  4. 通過後狀態會更新為「已完成」。
店長可在「訓練管理」建立新課程、指定對象，詳見第 27 章。

18. 月曆式班表 — 排班與鎖定

店長／有排班權限者 左側選單 → 月曆式班表

18.1 查看與編輯班表

  1. 選擇要編輯的年月。
  2. 表格橫軸為日期、縱軸為員工；點格子可更改班別。
  3. 變更會即時儲存。可搭配右側或上方的班別說明對照。
  4. 使用「匯出 PDF」可列印全店班表張貼。

18.2 排休鎖定

員工完成下月排休後，店長應：

  1. 檢查每人排休天數是否符合店規、人力是否足夠。
  2. 在班表頁執行「鎖定排休月」——鎖定後員工無法再改排休。
  3. 若需開放修改，可「解鎖」後通知員工限期重填。

18.3 其他店長功能

  • 國定假日一鍵：批次套用休假班別。
  • 颱風假／彈性出勤：依畫面引導設定當日出勤班別。
  • 工時警示：變形工時週期超時會以提示方式提醒（軟性警示，不會自動改班）。
  • 公告板：發布重要公告、公休通知。

19. 固定班表與單人排班

店長／有排班權限者

19.1 固定班表

路徑：固定班表

  • 為每位員工設定「每週固定」的班別（例如週一～五 B 班、週六 C 班）。
  • 可勾選個人規則：禮三晚班輪值、平日不排休、只能休半天等。
  • 固定班表會作為月曆排班的基礎，減少每月重複輸入。

19.2 單人排班

路徑：單人排班

  1. 選擇一位員工與目標月份。
  2. 選擇要套用的預設班（例如平日 B、週六 C）。
  3. 執行「套用」可一次填滿整月空白格子（不會覆蓋已手動修改或請假的日期）。
  4. 再至月曆班表微調個別日期。

20. 禮三晚班輪值（竹山店）

竹山店 左側選單 → 禮三晚班（集集店預設無此選單）

竹山店部分員工需輪值禮拜三晚班。此頁讓員工（或店長代操作）選擇當月哪些禮三「不值晚班」。

  1. 進入頁面，確認月份正確。
  2. 點選欲申請不值的禮三日期（有每月上限，系統會顯示剩餘次數）。
  3. 儲存後，排班時該日會套用對應的 off-duty 班別。

21. 審核請假／換班／加班／補登

店長／副店／老闆

21.1 在哪裡審核？

  • 進入對應申請頁面（請假、換班、加班、打卡補登），列表中會顯示「待審核」項目。
  • 或從通知中心點進待辦項目。

21.2 審核方式

店別審核規則
竹山店長、副店、老闆任一人按「核准」或「駁回」即可結案
集集須依序：店長審完 → 副店 → 老闆；畫面會顯示目前輪到誰

21.3 審核時請注意

  • 核准請假後，班表與打卡規則會自動連動，無需手動改班。
  • 駁回時建議填寫說明，方便員工重新申請。
  • 換班須確認雙方皆同意且人力配置合理。

22. 打卡管理與遲到管理

22.1 打卡管理

店長等 左側選單 → 打卡管理

  • 查看全店每日打卡紀錄。
  • 可代登打卡（員工忘記打卡、系統異常時）；代登不計入員工補登次數。
  • 可修正或刪除錯誤紀錄（請謹慎操作並註記原因）。

22.2 遲到管理

路徑：遲到管理

  • 列出員工遲到紀錄與分鐘數。
  • 已請假涵蓋的時段不會出現在遲到列表。
  • 結算薪資前可在此核對，與工時統計交叉比對。

23. 獎金登錄與薪資結算

23.1 獎金登錄（店長）

有獎金登錄權限、但無薪資結算權限者，進入「薪資結算」選單會看到獎金登錄畫面。

  1. 選擇要登錄的月份（通常為上月）。
  2. 為每位員工輸入個人獎金、團體獎金等項目。
  3. 可上傳獎金相關附件（保存約 30 天）。
  4. 儲存後由會計／老闆在結算時一併納入。

23.2 薪資結算（會計／老闆）

  1. 若需結算另一店，先在上方切換店別。
  2. 進入「薪資結算」，選擇結算月份。
  3. 系統依打卡、請假、加班、遲到、薪資結構自動試算。
  4. 逐人核對：底薪、津貼、加班費、獎金、扣款是否正確。
  5. 確認無誤後按「發布」——員工即可在「薪資查詢」看到並下載。
發布後若要修改，需由有結算權限者重新進入調整。發布前請務必仔細核對。

24. 員工管理

店長等 左側選單 → 員工管理

24.1 新增員工

  1. 按「新增員工」。
  2. 填寫姓名、帳號、初始密碼、角色（員工／主任／副店／店長等）。
  3. 選擇所屬店別（竹山或集集）。
  4. 填寫入職日（影響特休計算與年資）。
  5. 視需要勾選額外授權（排班、打卡管理等）。
  6. 儲存後將帳密告知該員工，並提醒修改密碼。

24.2 修改與停用

操作效果
修改角色／授權立即影響該員工可看到的選單與功能
設定到期日（最後工作日）到期後不再出現在班表排班名單
停用帳號無法登入，歷史打卡與薪資資料保留

25. 離職結清

店長等 左側選單 → 離職結清

員工離職時，用於試算與記錄結清項目（非取代會計正式作業）。

  1. 選擇離職員工、離職類型（資遣／自離／退休等）。
  2. 填寫最後工作日與結算月份。
  3. 系統試算：資遣費（新制／舊制）、未休特休代金、補休代金、當月打卡摘要等。
  4. 可儲存草稿，與會計確認後按「結案」。
  5. 結案時可寫入員工到期日並選擇是否停用帳號。
試算結果僅供內部參考，正式金額請以會計核算與勞基法規定為準。最後一個月薪資仍須至「薪資結算」處理。

26. 店家設定（店規調整）

店長／老闆 左側選單 → 店家設定

老闆切換店別後，可分別調整竹山與集集的設定。兩店設定完全獨立，修改一店不會影響另一店。

設定區塊常調整項目
基本資料店名、預設平日／週六班別
班別時段各班上下班時間、休息時段
班別目錄集集店自訂班別名稱與時數（竹山為 A–E）
功能開關禮三晚班、平日不排休、只能休半天、進階班別目錄
排休規則週六額度模式、平日額度、週日固定公休
出勤與加班可提早打卡分鐘、加班申請門檻、補登次數上限
審核方式任一結案／順序審核、審核關卡順序
假別規則各假別上限天數、給薪比例
權限政策副店是否等同店長、哪些角色可排班／結算薪資
打卡範圍GPS 圍籬位置（員工須在此範圍內才能打卡）
若不確定某項設定的影響，請先與老闆討論再變更。變更後建議通知全店同仁。

27. 訓練管理

店長等 左側選單 → 訓練管理

  1. 按「新增課程」，填寫課程名稱與說明。
  2. 上傳教材（文字內容、圖片或外部連結）。
  3. 新增測驗題目（選擇題／是非題）。
  4. 發布課程，員工即可在「教育訓練」看到。
  5. 於課程詳情查看每位員工的學習進度與測驗成績。

28. 常見問題與求助方式

狀況您可以這樣做
忘記密碼請店長在員工管理重設密碼
打卡顯示不在範圍內確認已開啟 GPS；站到店門口再試；仍不行請店長檢查打卡範圍設定
找不到某個選單可能您的角色沒有權限，或該功能在此店未開啟（如集集才有假別遞延）
排休無法選某天可能額度已滿、週日公休、或店長已鎖定該月
請假送出後沒動靜到通知中心查看；集集店可能等副店或老闆審下一關
薪資查詢沒資料該月尚未發布，請詢問會計預計發布日
班表與實際不符先查「我的班表」；有誤請告知店長在月曆班表修正
手機班表太擠「我的班表」可左右滑動；或用匯出圖片查看完整版面
換班被駁回確認是否為週日、雙方是否已同意、人力是否足夠
系統畫面異常先按 Ctrl+F5 強制重新整理；仍異常請拍照告知店長

求助管道

  2. 薪資相關 → 會計或老闆
