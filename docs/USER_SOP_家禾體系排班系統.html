1. 系統簡介與網址

本系統供排班、打卡、請假、薪資、店務等人事作業。竹山與集集共用同一套程式，資料依店別隔離。

項目說明
店內網址http://localhost:3000（主機開機後）
外網網址Tailscale Funnel（固定 *.ts.net，詳見部署 SOP）
建議瀏覽器Chrome、Edge（手機打卡需允許 GPS）
切換店別老闆／會計：畫面上方可切「竹山／集集」
手機使用外網時請用 4G 測試打卡，店內 Wi‑Fi 有時無法模擬外網情境。

2. 登入方式

2.1 員工登入

  1. 開啟登入頁 → 選「員工登入」
  2. 輸入帳號、密碼 → 成功後進入「上下班打卡」

2.2 管理端登入（店長／副店／主任／老闆）

  1. 選「管理端登入」
  2. 成功後進入「月曆式班表」
主任職位權限同員工，但必須用管理端登入。帳密由店長在員工管理建立。

2.3 登入後可能跳出的視窗

  • 公告（店長發布的重要訊息）
  • 薪資通知（薪資已發布時）
  • 排休提醒（每月 20 日起，若下月尚未選排休）

3. 角色與權限一覽

角色登入分頁主要能做什麼
老闆管理端兩店切換、權限政策、薪資結算、全部管理功能（不打卡）
店長管理端本店排班、審核、員工管理、獎金登錄、打卡管理
副店管理端預設同店長（可於店家設定關閉「副店等同店長」）
主任管理端權限同員工，可額外勾選排班等能力
員工員工打卡、請假、看班表、薪資查詢
會計管理端員工身分 + 勾選「薪資結算」→ 可切店結算薪資；排班打卡仍限所屬店

額外授權（Capabilities）

授權項目開啟後可進入
排班單人排班、固定班表、編輯班表
薪資結算薪資結算頁（通常僅老闆／會計）
員工管理員工管理、離職結清
店家設定店規、班別、權限政策
打卡管理打卡管理、遲到管理

4. 竹山店 vs 集集店 — 設定差異

項目竹山（耀聖）集集（家禾）
班別A–E 傳統班別進階班別目錄（多段休息）
禮三輪值晚班預設開啟預設關閉
平日排休額度每月 2 天0（以週六池為主）
週六排休固定額度 2 天月池模式
只能休半天關開
假別遞延關開
審核關卡店長任一可結案店長→副店→老闆 順序
變形工時兩週變形八週變形
打卡補登上限不限每月 2 次
GPS 圍籬設定鍵geofencegeofence:jiji
兩店設定在「店家設定」頁，請用上方切店後分別檢查，不可共用一份設定。

5. 兩店上線前檢查表（店長／老闆逐項勾選）

5.1 帳號與權限

  • 每位員工已建立帳號，所屬店別正確（竹山／集集）
  • 已改掉預設密碼（不可再用 admin123、boss123）
  • 店長、副店、會計角色與授權正確
  • 老闆可切換兩店並看到正確人員

5.2 店家設定（每店各做一次）

  • 店名、預設班、班別時段已確認
  • GPS 打卡圍籬座標正確（打卡管理或店家設定）
  • 排休規則（週六池／平日額度／週日公休）符合店規
  • 審核關卡（任一結案／順序審核）已設定
  • 假別上限與給薪（特休、病假等）已核對

5.3 班表與打卡

  • 當月班表已排定或可排
  • 員工可登入打卡，GPS 在圍籬內顯示綠燈
  • 店內、外網（4G）皆可開啟系統
  • 請假／加班／換班可送出，店長可審核

5.4 薪資（如有使用）

  • 員工薪資結構（底薪、津貼）已登錄
  • 會計可切店試算上月薪資
  • 發布後員工可在「薪資查詢」看到

5.5 資料庫權限（資訊／部署時）

  • 已執行 supabase db push 至最新 migration
  • 離職結清頁可正常開啟（無 permission denied）

6. 每月固定作業流程

時點負責動作
每月 1～15 日店長排定當月班表；維護固定班表
每月 20 日起員工「排休選擇」填下月休假日
排休截止前店長檢視排休是否額度正確 → 鎖定排休月
每月日常員工上下班打卡；請假／加班依規定申請
每月 1～5 日店長「獎金登錄」輸入上月獎金（如有）
每月 1～10 日會計／老闆「薪資結算」試算上月 → 核對工時 → 發布
發布後員工「薪資查詢」下載薪資單 PDF

7. 班表與排休

7.1 月曆式班表（/schedule）

  • 全員：查看班表、公告板、個人薪資條預覽
  • 店長：點格子改班別；鎖定／解鎖排休月；國定假日一鍵；匯出 PDF

7.2 我的班表（/my-schedule）

個人月曆；手機可左右滑動；可「匯出圖片」存檔。

7.3 排休選擇（/leave-selection）

  1. 選下個月
  2. 點日期切換排休（即時儲存）
  3. 注意週六／平日額度；集集可能有「只能休半天」

7.4 固定班表／單人排班

店長於「固定班表」設每週固定班；「單人排班」可一次套用預設班填滿整月。

8. 上下班打卡

8.1 一般流程

  1. 進入「上下班打卡」→ 等待 GPS 顯示「已在打卡範圍內」
  2. 按畫面大按鈕打卡（依班表顯示上班／下班時段）
  3. 遲到會要求填原因；下班逾時可一鍵申請加班

8.2 休假日來店加班

班別顯示「休假」時，使用下方「上班打卡（加班）」「下班打卡（加班）」；畫面會顯示進度與紀錄。

8.3 漏打卡

員工：「打卡補登」申請 → 店長審核。
店長：「打卡管理」可直接代登（不計入員工補登次數）。

9. 請假／換班／加班

功能路徑重點
請假請假申請選假別、時段；特休會扣餘額；核准後班表顯示休假
特休總表請假申請內連結查年度配額與已休天數
換班換班申請選對象與互換日期；週日公休日不可換
加班加班申請選補休或加班費；店長審核
假別遞延假別遞延僅集集預設開啟
審核：竹山通常店長直接核准；集集依關卡順序（店長→副店→老闆）。

10. 工時統計與遲到

工時統計（/attendance）

  • 預設顯示上個月（方便結薪）
  • 員工只看自己；店長／會計可看全店（會計可切店）
  • 可匯出 CSV、打卡 PDF

遲到管理（/attendance/tardiness）

店長檢視遲到紀錄；已請假覆蓋時段不計遲到。

11. 薪資結算與查詢

店長 — 獎金登錄

有獎金權、無結算權者進入「薪資結算」頁會看到獎金登錄，輸入個人／團體獎金。

會計／老闆 — 薪資結算

  1. 切換正確店別
  2. 選擇結算月份（預設上月）
  3. 核對工時、請假扣款、加班、遲到
  4. 按「發布」→ 員工即可查詢

員工 — 薪資查詢

僅能看已發布月份；可匯出 PDF／Excel。

12. 員工管理與離職結清

員工管理

  • 新增：帳號、密碼、角色、所屬店、入職日
  • 到期日：最後工作日；到期後班表不顯示
  • 停用：無法登入，歷史資料保留

離職結清（/employees/offboarding）

  1. 選員工、離職類型（資遣／自離／退休）
  2. 填最後工作日、結算月份
  3. 系統試算：資遣費、未休特休、補休、當月打卡
  4. 儲存草稿 → 確認後「結案」（寫入到期日、可停用帳號）
試算僅供內部參考；正式金額請會計／勞檢確認。最後月薪資仍至「薪資結算」處理。

13. 店務需求、訂餐、公告板

店務需求（/shop-ops）

叫藥、日常採購、客人訂購、客訂管理（匯出 Excel／PDF）。

訂餐（/meal-order）

發起訂餐活動 → 員工填單 → 負責人標記已訂購；可發公告。

公告板（班表頁上方）

店長可發公告、公休通知；員工可發代班需求、交班留言。

14. 教育訓練

  • 教育訓練：員工學習課程、測驗
  • 訓練管理：店長建立課程、上傳教材、追蹤進度

15. 日常維護與更新

更新網站（不需重啟外網）

powershell -ExecutionPolicy Bypass -File scripts\windows-update-site.ps1

完成後瀏覽器 Ctrl+F5 強制重新整理。

外網打不開時

powershell -ExecutionPolicy Bypass -File scripts\windows-restore-funnel.ps1

資料庫更新

supabase db push --local
